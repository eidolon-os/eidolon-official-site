# Eidolon OS official site

Eidolon OS 的官方愿景站点。

核心命题：**一个 Eidolon，贯穿人、车、家与工作。**

- `/`：Eidolon OS、One 旗舰、官方外设、EID-X 生态与连续场景总览
- `/os`：个人 AI 操作系统的能力、架构与设备运行模式
- `/one`：Eidolon OS 官方旗舰与 One 外设产品家族
- `/manifesto`：从设备互联到个人智能体连续存在的产品哲学
- `/protocol`：面向官方外设、汽车、家庭设备与机器人的 EID-X 设备协议

完整产品思想见 [VISION.md](./VISION.md)。
